# FlyThe BG Security Policy

## Reporting a vulnerability

Please report security vulnerabilities privately to **support@flythebg.com**.

Include the affected URL or component, steps to reproduce, expected behavior, observed behavior and any safe proof that helps confirm the issue.

## Do not include secrets

Never publish or email active passwords, Hugging Face access tokens, Cloudflare credentials, session tokens or private user files.

## Scope notes

The FlyThe BG browser client should never receive the Hugging Face credential. The protected background-removal route is designed to validate inputs and avoid persistent user-media storage managed by FlyThe BG.

## Responsible disclosure

Please allow reasonable time for investigation and remediation before publicly disclosing an exploitable issue.
