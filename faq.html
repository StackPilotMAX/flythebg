Frequently asked questions.

Do you upload every file?

Image and video compression are designed to run in your browser. Background removal sends the image through the protected server route to the private Hugging Face Space.

Can a GitHub clone expose the Hugging Face key?

Not when the deployment secret is stored only in Cloudflare environment variables. It is never committed to the repository.

Can I run background removal locally?

Yes. The repository includes a Python helper using rembg, Pillow and ONNX Runtime.

Are results guaranteed to be perfect?

No. Automated background removal can make mistakes around hair, fine edges, transparency and shadows. Review important results.

How do I contact you?

Email stackpilotfe@outlook.com. Email is used because FlyThe BG is currently an independent, non-registered project.
