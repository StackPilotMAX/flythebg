# Contributing to FlyThe BG

Thanks for helping improve the project.

## Before making a change

Read the project privacy, security and code-of-conduct pages. Keep secrets out of source code, documentation, screenshots and logs.

## Development principles

Prefer accessible, mobile-friendly interfaces, clear privacy boundaries, small focused changes and direct explanations. Do not add hidden uploads, tracking or persistent user-file storage without updating the product and legal documentation.

## Pull requests

Use pull requests for community contributions. Repository maintainers may also apply direct changes to the main branch during active maintenance.
